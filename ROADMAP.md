# Happy Farm Roadmap

Milestones describe intended outcomes, not fixed delivery dates. Scope may evolve as engineering work progresses.

## M0 — Project foundation
- [x] Public repository and playable prototype.
- [x] Documentation, contribution guidance and release conventions.
- [ ] Modular application structure and reproducible local build.
- [ ] Automated validation and deployment workflow.
- [ ] Asset licensing and attribution register.

## M1 — Game foundation
- [ ] Select and integrate the 2D game engine.
- [ ] Scene lifecycle, camera, input and responsive scaling.
- [ ] Layered tile-based farm world and camera navigation.
- [ ] Placement, selection, rotation and removal of world objects.
- [ ] Asset loading, animation and audio pipelines.

## M2 — Core farming
- [ ] Data-driven crop definitions.
- [ ] Soil preparation, planting, watering and growth timers.
- [ ] Harvesting, inventory and barn capacity.
- [ ] Seed shop, crop selling and economy rules.
- [ ] Persistent saves with schema versioning.

## M3 — Farm life
- [ ] Animal entities, habitats and care loops.
- [ ] Buildings and production chains.
- [ ] Decorations, fences, paths, landscaping and ponds.
- [ ] Expandable land and unlock progression.

## M4 — Progression and content
- [ ] Player levels, XP, quests and achievements.
- [ ] Orders, markets and balanced economy.
- [ ] Seasonal content and events.
- [ ] Accessibility, sound design and visual polish.

## M5 — Online features
- [ ] Evaluate accounts and cloud-save architecture.
- [ ] Neighbour visits, gifting and cooperative play.
- [ ] Server-authoritative economy and multiplayer safeguards.
- [ ] Privacy, abuse prevention and operational monitoring.

## M6 — Stable release
- [ ] Performance, compatibility and security review.
- [ ] Automated gameplay-system tests.
- [ ] Save migration and recovery validation.
- [ ] Release candidate and stable 1.0.0 release.

## Scope principles
- Create an original Happy Farm identity while retaining the approachable classic farming-game feel.
- Do not copy proprietary FarmVille artwork, branding, source code or protected content.
- Prefer durable systems over one-off visual demonstrations.
- Design single-player systems cleanly before adding networked features.
