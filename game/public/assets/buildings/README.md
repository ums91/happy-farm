# Building assets

Each building has its own folder. Use standalone transparent PNGs for each upgrade level, with a consistent isometric camera angle, visual scale, and ground footprint.

Naming: `<building>-level-1.png` through `<building>-level-6.png` where six levels are appropriate. Do not include labels, UI, or progression arrows in production assets.

Folders: farmhouse, windmill, greenhouse, village-bakery, chicken-coop, cow-shed, barn, silo, well, workshop, stable, water-tower.
