# Asset Library

Place original or appropriately licensed game assets in this directory.

Suggested structure:
- `sprites/` — characters, crops, animals and animated objects.
- `tiles/` — terrain, paths, water and world tiles.
- `buildings/` — houses, barns, shops and production facilities.
- `ui/` — icons, buttons, panels and interface textures.
- `audio/` — music and sound effects.

For every third-party asset, record the asset name, creator, source URL, license, required attribution and any modification made in an asset register before including it in the game.

Do not add extracted FarmVille assets, proprietary art, unlicensed fonts, or content with unclear redistribution rights. The current scene uses procedural vector placeholders and does not require external sprite assets.
