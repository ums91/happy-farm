# Security Policy

## Supported versions
Happy Farm is an early development project. Security fixes are applied to the active default branch; no stable support window is defined yet.

## Reporting a vulnerability
Do not publish exploit details, credentials, personal information or sensitive vulnerability details in a public issue. Use GitHub private vulnerability reporting if enabled; otherwise contact the repository maintainer privately through GitHub.

Include a concise impact description, safe reproduction steps, affected commit/browser/environment and any suggested mitigation.

## Secret handling
Never commit API keys, tokens, passwords, private save data or signing credentials. All client-side code and assets deployed to GitHub Pages are public.
